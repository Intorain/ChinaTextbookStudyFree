# v1.5.0 五册教材发布与线上验收

发布沿用 https://d3nmsqi4n72idj.cloudfront.net/，更新现有东京 S3/CloudFront，不更换成绩存储的浏览器 origin。保留所有旧对象及上一版本资源包；可用上一部署快照重新上传并清理 CDN 缓存回退。

本版完整 Web 资源包为 `v1.5.0-five-textbooks`，支持全新安装及原目录升级，包含全部 50 册版本、页面、资源和匹配源码。此前仅用于本地验证的五册增量包不是完整安装包。iOS 数据及 AAC/M4A 按 50 册分别打包，同一 Release 的 `ios-manifest.json` 提供大小和校验和。iOS 客户端源码下载地址同步更新；本次不分发或签署 App Store 二进制。

服务工作线程轮换教材与页面缓存，不访问或清空原学习存储。新版采用独立 ID；旧版文件、旧成绩、错题、奖励和旧版选择继续保留。

## 验收方法

1. 发布前通过线上产品的“导出存档”保存既有档案，另建发布验证档案，完成旧版教材的一课并导出存档。
2. 比对全部旧教材内容指纹；准备独立静态部署快照并校验媒体引用，保留上一线上快照。
3. 对完整材料包执行全新静态安装、来源安装与原目录升级，验证包和文件 SHA-256；iOS 验证全量引用、CRC、SHA-256 及解码样本。
4. 上传资源后更新页面，清理 CloudFront 缓存并等待完成；使用同一线上地址重新加载。
5. 验证五册新旧入口、课时及挑战、页图、MP3 类型和 Range；比对线上旧 JSON 的内容指纹及静态部署文件清单。
6. 在未清除浏览器存储的情况下确认旧版通关、星星和成绩保留，新版没有被自动通关；完成新版的一课，确认两版成绩并存。恢复原档案并再次导出，核对原有成绩和错题未变化。

线上与公开下载验收的机器记录随 Release 的 `VALIDATION.json` 提供；包含验收边界、资源清单及浏览器实测结果。用户其他设备上的存储不在当前浏览器可读范围，验证结论不替代每台设备的实际使用状态。

## 回退

不删除旧资源。重新上传上一完整部署快照，创建 CloudFront `/*` 缓存失效并等待完成。成绩存储结构及原 ID 未改变，回退不需要还原或清空学习存档。
